# Card Acceptance Working Group

The Card Acceptance Working Group exists to make card payments work over x402 alongside stablecoins. The group defines how card-based payments fit into the existing x402 model of schemes, networks and facilitators, so that facilitators, PSPs and sellers share one open approach instead of each inventing their own.

The [charter](CHARTER.md) sets out the group's objectives, scope, deliverables and working model.
